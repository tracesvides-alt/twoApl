# どうぶつのおでかけガレージ

2〜3歳の子どもが、車を走らせながら動物たちの暮らしを発見できる、スマートフォン・タブレット向けのPWAです。

遊ぶたびにガレージの仲間と庭のアイテムが増え、集めたものを好きな場所へ動かせます。文字を読まなくても、見て、タップして、ドラッグするだけで遊べます。

## 主な体験

- **3つのあそび**：車を走らせる、動物を探す、荷物を運ぶ
- **ガレージの成長**：遊ぶと新しい車・動物・庭のアイテムが増える
- **自由に動かせる庭**：集めたアイテムをドラッグして、自分だけの庭をつくる
- **やさしい成功演出**：音、光、振動、アニメーションで「できた！」を伝える
- **失敗のない設計**：間違えても止まらず、自然にもう一度試せる
- **保護者設定**：音、振動、説明表示、進行状況の確認とリセット
- **オフライン対応**：インストール後は通信がなくても起動可能

広告、課金、外部リンク、チャット、SNS、ユーザー登録はありません。

## 起動方法

Node.js 24.xを用意してください。

```bash
npm install
npm run dev
```

表示されたURLをスマートフォンまたはタブレットで開くと遊べます。PCのブラウザでも動作確認できます。

本番用の静的ファイルを作成して確認する場合は、次を実行します。

```bash
npm run build
npm run preview
```

PWAとしてホーム画面に追加するには、HTTPSで配信してください。開発中のローカル確認では、ブラウザのインストール機能を使えます。

## 遊び方

### 子ども向け画面

1. トップ画面で大きな「スタート」ボタンをタップします。
2. ガレージで車を選びます。左右の矢印で選べます。
3. 画面下の大きなカードから、遊びたいあそびをタップします。
4. 画面で光っている場所をタップまたはドラッグします。
5. 成功すると、車が走る、動物が喜ぶ、アイテムが増えるなどの演出が起こります。
6. 「もういちど」で同じあそびを続けたり、「ガレージへ」で集めたものを確認したりできます。

### 庭の模様替え

ガレージの庭では、配置済みの車や動物、アイテムを指でドラッグして移動できます。配置は端末内に自動保存されます。

### 保護者設定

画面右上の歯車ボタンから設定ページを開けます。保護者向けページでは次を変更できます。

- BGM、効果音、振動、ヒント表示のオン・オフ
- 集めた車・動物・庭のアイテムの確認
- 進行状況のリセット

リセットは確認ダイアログを表示してから実行します。子どもが偶然触れても進行状況を消しにくいよう、設定ページへの入口と操作を分けています。

## 長く遊べる仕組み

1回のあそびは短くても、遊ぶたびにガレージが変化します。獲得したスターに応じて、車、動物、庭の飾りが段階的にアンロックされます。

同じあそびでも、登場する動物や走るコース、運ぶ荷物が変わります。完成した庭を眺めたり、配置を変えたり、次に何が増えるかを確かめたりできます。

## 技術構成

- React 19
- Vinext（Next.js互換のViteベースランタイム）
- TypeScript
- CSS（モバイル向けレスポンシブレイアウト）
- Web Audio API（効果音）
- Service Worker（オフライン起動）
- `localStorage`（端末内の進行状況保存）

サーバー側のデータベースやアカウントは使用しません。プレイ状況、設定、庭の配置は遊んでいる端末のブラウザに保存されます。

## ファイル構成

```text
app/
  page.tsx                 子ども向けメイン画面
  motor-park.css           メイン画面のスタイル
  parents/
    page.tsx               保護者設定画面
    parents.css            設定画面のスタイル
lib/
  game.ts                  ゲーム状態、報酬、保存データ
  garden-layout.ts         庭アイテムの配置とドラッグ処理
  use-game.ts              ゲーム状態を扱うReactフック
  sound.ts                 BGM・効果音・振動
public/
  art/                     車・動物・庭のビジュアル素材
  icons/                   PWAアイコン
  manifest.webmanifest     PWAマニフェスト
scripts/
  build-sw.mjs             Service Worker生成
  serve.mjs                静的ビルド確認用サーバー
tests/                     ゲーム状態・保存・オフラインのテスト
```

## 開発用コマンド

| コマンド            | 内容                           |
| ------------------- | ------------------------------ |
| `npm run dev`       | 開発サーバーを起動             |
| `npm run build`     | 本番用静的ビルドを作成         |
| `npm run preview`   | `dist/client`を配信            |
| `npm run typecheck` | TypeScriptの型チェック         |
| `npm run lint`      | Oxlintで静的解析               |
| `npm test`          | Node標準テストランナーでテスト |
| `npm run format`    | Oxfmtで整形                    |

GitHubへpushすると、`.github/workflows/ci.yml` が型チェック、Lint、テスト、ビルドを自動実行します。

## Vercelへのデプロイ

1. [VercelのNew Project](https://vercel.com/new)を開きます。
2. GitHubの `tracesvides-alt/twoApl` をImportします。
3. Root Directoryはリポジトリのルートのままにします。
4. `vercel.json` がBuild Command、Output Directory、Install Commandを自動設定します。
5. Node.js Versionは24.xを選んでDeployします。

以後は `main` へpushするたびにVercelが自動でビルドとデプロイを実行します。
