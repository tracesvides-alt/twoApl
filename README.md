# どうぶつの おでかけガレージ

2〜3歳の子が、どうぶつと車を選んで出かけ、小さなお手伝いで自分のモーターパークを育てるWebゲームです。ゲーム用バックエンド、ログイン、広告、課金、通知、外部リンクはありません。進み具合は端末のブラウザ内だけに保存します。

## 起動

Node.js 24.19以上・npmを使用します。

```sh
npm ci
npm run dev
```

開発画面はターミナルに表示されるURL（通常 http://localhost:3000 ）です。

本番用の静的ファイルを作って確認する場合：

```sh
npm run typecheck
npm test
npm run build
npm run preview
```

プレビューは http://localhost:4173 。`dist/client/` の内容をHTTPS対応の静的ホスティングに配置すれば動きます。アプリ用サーバーの運用は不要です。`npm start` も静的プレビューを起動します。ポートは環境変数 `PORT` で変更できます。

同一Wi-Fiのスマホからは、開発サーバーのNetwork URLへアクセスできます。ただし、通常のLAN上のHTTPではService Workerが動かないため、PWA・オフラインの確認にはHTTPSが必要です。PCのlocalhostは開発用の例外です。`file://` でHTMLを直接開く形式には対応していません。

## 遊び方

1. 大きなどうぶつの絵と車の絵をタップして選びます。最初はくま・うさぎ、黄色い車・ジープが選べます。
2. 黄色い矢印で出発。道か矢印を3回タップすると目的地に着きます。道をスワイプしても進めます。
3. お手伝いをします。
   - **もぐもぐ ピクニック**：3つの果物・野菜をタップ、またはかごへドラッグ。うまく入らなくても元に戻るだけです。
   - **あわあわ せんしゃ**：5つの汚れをタップしたりなぞったりすると、車がきれいになります。
   - **すくすく おはな**：3つの鉢を2回ずつタップすると、芽が育って花が咲きます。
4. どうぶつからおみやげを受け取り、家の絵のボタンで庭に帰ります。
5. 増えた仲間や道具をタップすると音と動きが返ります。車の絵を選び直して、またお出かけできます。

遊びは順番に切り替わりますが、ガレージの下の3つの絵から好きな遊びを選ぶこともできます。途中のお出かけがある間は、その続きが優先されます。

## 企画・UX

### 1. コンセプト

「車を選ぶ → 出かける → だれかの役に立つ → 自分の場所が変わる」。一回の成功を、その場の演出だけでなく、次に訪れる庭の変化につなぎます。

### 2. 2歳児が楽しめるようにした点

読むこと、数を理解すること、正確なドラッグを必須にしていません。どの遊びもタップだけで完了できます。絵を大きくし、触った結果をすぐ返します。制限時間、ゲームオーバー、減点、強い不正解音はありません。幼児の操作や好みには個人差があるため、実際の利用では保護者と一緒に反応を見てください。

### 3. 基本ループ

ガレージ → 3回の移動 → 3〜6回のお手伝い → おみやげ → 庭 → ガレージ。好きなところでやめられ、途中でも再開できます。成功画面には「きょうは おしまい」もあります。

### 4. 長く遊べる仕組み

最初の8回で順番に、お花・きつね・トラック・ぞう・すべりだい・バス・テント・虹が増えます。仲間と車は次のお出かけで実際に選べるようになります。庭の物は9回目以降も順番に育ち、24回で全て3段階目になります。その後も3種類の遊び、果物の違い、花の色、車とどうぶつの組み合わせ、庭の反応や空の切り替えを自由に楽しめます。コンテンツが無限に増える方式ではありません。

庭の花や虹は触ると色が変わり、道具・どうぶつは跳ねたり音を鳴らしたりします。期限、連続ログイン、ランダムな当たり外れ、周回ノルマはありません。

### 5. 達成感

触れた場所に音・変化・チェックが返り、全てできると短いファンファーレ、紙吹雪、どうぶつのお礼、おみやげの登場で祝います。点数や他人との比較はありません。音を消しても視覚だけで進めます。

### 6. 画面構成・デザイン

ガレージ／道／3種類のお手伝い／おみやげ／庭／休憩。ネイビーの操作盤、ブルー、黄色い出発ボタン、立体感のある玩具風の車とどうぶつで統一しています。保護者用の説明をゲーム面に大量に表示しません。

右上の設定は「7 → 2 → 9」の順番で開きます。効果音・アニメーションの切り替え、保存状態、ホーム画面への追加方法、遊び方、休憩を用意しています。アニメーションを無効にでき、OSの `prefers-reduced-motion` にも対応します。画面ズームを禁止していません。

### 7. 技術構成

- React 19 / TypeScript / Vinext・Vite の静的エクスポート
- Tailwind CSS、独自CSS、Lucideアイコン
- 既存のShadcn / Base UIのDialog・Switch（保護者設定）
- Pointer Eventsによるタップ・ドラッグ・スワイプ
- Web Audio APIで端末内生成する短い効果音。音声素材のダウンロード不要
- `localStorage` にバージョン付き状態・直前のバックアップを保存
- Manifestとビルド時生成Service WorkerによるPWA
- 外部フォント・CDN・分析SDK・ゲームAPIへの依存なし

## 保存・PWA

操作ごとに同期保存します。お出かけの途中、集めた物、選択した車・仲間、庭の反応、空、設定が対象です。成功状態も保存し、再読み込みや連打でおみやげが二重に増えないようにしています。

保存形式を検証し、壊れている場合は直前のバックアップを読みます。保存が拒否された場合も遊べますが、設定ボタンに印を出し、保護者画面で永続保存できないことを伝えます。ブラウザのデータ削除やストレージの自動削除では記録が失われます。クラウド同期や端末間の引き継ぎはありません。

初回はオンラインで本番画面を開きます。準備できるとヘッダー（大きい画面）または保護者設定にオフライン準備完了が表示されます。

- iPhone / iPad：Safariの共有メニュー →「ホーム画面に追加」
- Android：Chromeのメニュー →「ホーム画面に追加」または「アプリをインストール」

Service Workerは本番ビルドのみで登録します。全ての静的ファイルを事前キャッシュし、ネットワークがなくても起動できます。更新は既存のプレイを強制再読み込みせず、古いタブを閉じた後に反映します。ホスティングのルート配下に配置してください。サブディレクトリ配信にはアセットパス・scopeの調整が必要です。

SitesのプレビューURLが所有者限定の場合、配信側で既存のChatGPTアカウントによる認証が必要になることがあります。ゲーム自体にはアカウント機能はなく、静的ファイルを通常のHTTPSホスティングに置けば認証なしで配信できます。

## 検証とファイル構成

`npm test` は3種類の全ループ、途中復帰、重複報酬防止、24回分のアンロック・成長、範囲外入力、保存復元・バックアップ・保存不可を確認します。ブラウザでの操作・画面・オフラインの確認結果は `TESTING.md` を参照してください。

- `app/page.tsx`：ゲーム画面とジェスチャー
- `app/globals.css` / `app/motor-park.css`：レスポンシブ表示と玩具風デザイン
- `lib/game.ts`：ゲーム状態・遷移・保存形式検証
- `lib/use-game.ts`：同期保存とReactの接続
- `lib/sound.ts`：効果音生成
- `public/art/`：同梱アート
- `public/manifest.webmanifest` / `public/icons/`：PWA設定とアイコン
- `scripts/build-sw.mjs`：キャッシュ対象を自動収集してService Worker生成
- `scripts/serve.mjs`：ビルド後の静的ファイル確認
- `tests/`：ゲーム・保存の回帰テスト

オフライン機構は [MDNのService Workerガイド](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Offline_and_background_operation) の仕組みを利用しています。

## 保護者設定・庭の移動（追加機能）

右上の設定アイコンから `/parents/` の専用ページに進みます。数字を `7 → 2 → 9` の順で押すと、効果音・アニメーション、保存状態、遊び方、PWAの追加方法、庭の整列、リセットを操作できます。

- 庭のアイテムは指でつかんで移動できます。タップすると従来どおり音や動きが返ります。
- 指を離した場所を保存します。枠の外へドラッグしても、アイテム全体が枠内に収まります。
- 移動途中のキャンセルは元の配置に戻します。矢印キーでも移動できます。
- まだ動かしていないアイテムは、スマホでは3列、広い画面では4列に並びます。
- 「配置だけ整える」は、集めた物や進み具合を残して配置を戻します。
- 「ゲームをリセットする」は、数字の入口に加えて「リセット」の文字入力と最終ボタンが必要です。ゲーム記録・設定・復旧用バックアップを初期化します。他のアプリの保存データは触りません。
- 以前の保存データも、進み具合を失わずに配置情報を補って読み込みます。

タップできる物には明るい枠を付け、次に触る対象には指のマークを表示します。ひとつできると次の対象へマークが移ります。動きをオフにしても目印は残ります。

## Windowsのビルドについて

同梱のVinext beta.5がビルド直後にプロセスを強制終了すると、Windowsでlibuvの終了処理が競合するため、`scripts/windows-build-exit.mjs` で成功時だけイベントループの自然終了を待ちます。エラー終了や例外はそのまま失敗として扱います。`npm run build` に組み込み済みです。Lintはアプリ自身の `app/`・`lib/`・`scripts/`・`tests/` を対象とし、生成済みのUIライブラリは対象外です。
